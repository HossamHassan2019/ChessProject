
# 🏆✨ CHESS PROJECT ✨🏆

This is a chess platform which will be used to play and create games.

## 📚 How to run Chess app

### 🔗 Docker

1. Make sure you have Docker and Docker Compose installed on your machine.
2. Clone the repository.
3. Run `git submodule update --init --recursive` from the root directory.
4. Copy the`.env.example` file and rename it to `.env` file and fill in the necessary environment variables.
5. Run `docker compose up`.
